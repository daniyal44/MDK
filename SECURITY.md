# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of **MDK Works** and its software platforms seriously.

If you believe you have found a security vulnerability in this repository or associated live apps, please do NOT create a public issue.

Instead, please send an encrypted or direct email to:
📧 **m.daniyalkhan490@gmail.com**

Please include:
1. Type of vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Impact assessment.

We will review your submission and respond within 48 hours.
